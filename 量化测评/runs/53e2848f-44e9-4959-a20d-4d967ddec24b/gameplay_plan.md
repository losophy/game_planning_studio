### 核心循环
**局内单次循环（单波/单局）**：战前规划（选择初始资金与塔位） → 拖拽部署防御塔 → 波次迎战（自动攻击+手动释放战术技能/利用环境道具） → 波间结算（拾取金币、快速升级/修复） → 动态调整（根据下一波敌人类型微调布局或击碎掩体改道） → 通关/失败结算。
**局外长期循环**：闯关获取“星星/灵感点数” → 解锁新塔/被动天赋/主动技能 → 挑战更高难度/词缀关卡 → 收集图鉴与成就 → 形成“验证策略→获取资源→强化能力→挑战新机制”的正向留存闭环。

### 战斗/操作机制
**战斗类型**：即时制自动战斗 + 策略布阵 + 单局轻微操（适配移动端单手操作）。
**核心操作**：
- **单指交互**：点击空地放置塔，长按拖拽调整位置（波间或暂停状态下），点击已部署塔进行升级。
- **战术技能**：全局共享1-2个主动技能槽（如“猛火快炒”：对路径敌人造成一次爆发伤害；“急冻保鲜”：大范围减速3秒）。技能随关卡进度解锁，冷却独立，不干扰自动战斗节奏。
- **环境互动**：点击或攻击关卡内的“可破坏掩体”（木箱、冰墙、藤蔓）。击碎后可短暂开辟捷径或制造火力交叉点，玩家需权衡“提前清障加速敌人”还是“保留掩体拖延控场”。
**塔系设计**（4基础型，契合“厨房”主题）：
1. **菜刀塔**：单体高伤，攻速中等，适合处理高血量精英。
2. **炒锅塔**：范围溅射，攻速慢但单次伤害高，克制密集人海。
3. **冰箱塔**：减速/冰冻控制，伤害低但提供关键输出窗口。
4. **榨汁机塔**：高频攻击，附带“破甲”效果，专克高护甲单位。
**敌人AI与波次节奏**：沿固定单线/分支路径移动；遇障碍物自动寻路绕行；受控时优先攻击最近单位。波次采用“铺垫→压力测试→机制检验→BOSS战”结构，单局时长控制在3-5分钟。

### 成长系统
**局内成长（单局资源循环）**：
- 金币驱动：击败敌人/波次奖励获取金币，用于建造新塔或升级现有塔（T1→T2→T3）。
- 波间抉择：每波结束后提供“临时Buff”三选一（如本波金币+20%、冰箱塔范围+15%、全局攻速+10%），增加单局策略变数与重玩价值。
**局外成长（Meta进度）**：
- **主厨手册（科技树）**：通关获得“灵感点数”，用于解锁新塔类型、强化基础属性（全局金币获取、初始资金）、解锁主动技能槽位。
- **塔系进化**：非纯数值堆砌。T2解锁“被动光环”（如冰箱周围塔获得减速加成），T3解锁“机制质变”（如榨汁机攻击附带“破甲”层数，叠满触发斩杀）。
- **进度验证**：每关1-3星评价（基于通关时间、剩余生命、金币消耗）。满星解锁“地狱厨房”模式（敌人词缀+路径变化），提供硬核玩家追求目标。

### 数值框架
- **属性体系**：生命值(HP)、攻击力(ATK)、攻击间隔(ASPD)、射程(Range)、控制时长(CCD)、护甲/抗性(ARM/RES)。
- **核心公式**：
  - `实际伤害 = ATK × (1 + 伤害加成%) × 暴击系数 - 目标护甲`（保底10%伤害，防止完全免疫）
  - `有效生存时间 = 敌人HP / (塔群DPS × 减益乘区)`（用于校准波次难度）
  - `经济模型`：第N波金币产出 = `基础值 × (1.15^N)`；T1造价50，T2造价150，T3造价400（呈1.5-2倍递增，强制资源取舍与优先级排序）
- **平衡原则**：
  1. **剪刀石头布克制链**：减速塔为DPS创造窗口，AOE塔克制人海，单体/破甲塔克制精英/BOSS。无绝对最优解，需动态搭配。
  2. **边际递减防堆叠**：同类型塔相邻放置时，光环/控制效果叠加效率递减（最高80%），防止“无脑铺同一种塔”破坏策略性。
  3. **动态难度校准**：敌人血量与波次节奏严格对标“最优解DPS曲线”。预留15%容错空间，确保休闲玩家可过，硬核玩家可追求极限操作。
  4. **资源卡点设计**：前3波强制体验“基础塔+升级”循环；第5波引入经济压力测试；第8波引入机制检验（飞行/护甲/分裂），平滑学习曲线。

### 玩法亮点
1. **“厨房连携”空间策略**：相邻放置特定塔触发“菜谱Combo”（如冰箱+榨汁机=“冰镇果汁”，减速敌人额外受到持续伤害；炒锅+菜刀=“爆炒双拼”，AOE后单体伤害提升）。无需复杂UI，纯靠位置摆放实现深度，完美契合“简单上手、精通有深度”的定位。
2. **动态路径博弈**：环境掩体是“战术杠杆”而非装饰。玩家可主动击碎掩体改变敌人行进路线，将敌人引向火力交叉点，或故意保留掩体阻挡高速怪。单线塔防由此产生“伪多线”策略感，有效化解玩法重复风险。
3. **单手碎片化体验**：全自动化战斗 + “子弹时间”暂停 + 一键升级/波间抉择。单局3-5分钟，操作负担极低，完美匹配移动端通勤/排队场景，同时通过Combo与路径选择保留策略内核。
4. **主题化机制深度融合**：“蔬菜怪”与“厨具塔”不仅是美术包装，更深度绑定玩法逻辑（如“洋葱怪”死亡释放毒雾考验走位、“烤箱塔”提供持续灼烧）。视觉辨识度与玩法记忆点高度统一，降低学习成本的同时提升社交传播性。
