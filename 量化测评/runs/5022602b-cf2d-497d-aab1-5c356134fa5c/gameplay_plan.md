### 核心循环
**单次循环（局内/关卡内）**
观察环境标记 → 规划移动路径 → 执行精准操作（跳跃/冲刺/抓墙/变向） → 触发动态物理区或机关 → 成功抵达检查点 / 失败碎裂 → “场景记忆”记录本次轨迹与状态变化 → 利用残影信息调整策略重试 → 突破难点/收集隐藏要素 → 进入下一区域。

**长期循环（Meta/全局）**
推进主线关卡 → 解锁新移动能力 → 回溯已通关区域探索隐藏路径 → 收集“记忆棱镜”与“时空日志” → 解锁剧情碎片/辅助模式/外观特效 → 挑战速通榜/无伤/全收集成就 → 导出录像分享/参与社区竞速。

**循环验证**
- **新手体验**：前3关仅开放基础移动+跳跃，通过“残影提示”降低试错成本，Coyote Time与Jump Buffer保证基础容错，确保15分钟内建立操作信心。
- **中期目标**：引入动态重力区与“场景记忆”解谜，能力解锁（如空中冲刺）打开新路线，收集品提供明确探索动机，维持“学习-掌握-突破”的正向反馈。
- **长期追求**：高难度挑战（限时、无伤、全收集）、能力组合速通路线、社区排行榜与录像回放系统，为硬核玩家提供深度钻研空间。

### 战斗/操作机制
*(注：本作无传统战斗，此处聚焦核心操作、物理交互与手感调校)*

**核心操作与手感调校**
- **输入逻辑**：移动（摇杆/方向键）+ 跳跃 + 冲刺 + 抓墙/蹬墙 + 能力键。采用“输入队列”机制，允许在落地前0.1秒预输入下一次操作。
- **手感参数**：Coyote Time（0.12s）、Jump Buffer（0.1s）、空中惯性衰减（0.85/帧）、冲刺启动延迟（0.05s）与硬直取消窗口。所有参数支持关卡内动态微调，确保“操作可预期、失误可复盘”。
- **死亡与重生**：即时碎裂动画（<0.3s）+ 检查点无缝重生（<0.5s），无Loading界面，维持心流连续性。

**动态物理与场景交互**
- **物理区域标识**：低重力（蓝色光晕/慢速粒子）、高弹跳（橙色网格/清脆音效）、零摩擦（紫色流光/滑步提示）、重力反转（倒置UI/环境翻转）。区域边界清晰，切换时给予0.2s视觉缓冲。
- **动量守恒规则**：进入新物理区时保留当前速度矢量，仅改变加速度/重力系数。玩家需利用“惯性滑行+区域切换”完成长距离跨越，形成“物理拼接”玩法。

**“场景记忆”机制落地**
- **残影生成**：玩家踩踏脆弱平台、触发机关或死亡时，该位置生成半透明“记忆残影”，持续至本Checkpoint重置或手动清除。
- **残影交互**：残影可作为临时踏板（承重1次）、显示隐藏机关触发顺序、或标记安全落点。连续失败3次后，残影自动高亮提示最优路径，实现“失败即资源”。

### 成长系统
**能力解锁路径（机制驱动，非数值成长）**
- **基础阶段**：移动、跳跃、抓墙（教学关解锁）
- **进阶阶段**：空中二段跳（第3关）、短距冲刺（第6关）、蹬墙跳（第9关）
- **高阶阶段**：重力锚点（可短暂锁定重力方向，第14关）、相位穿透（穿过特定晶体，第18关）、动量蓄力（长按蓄力改变初速，第22关）
- *设计逻辑*：能力解锁后自动回溯至前期关卡，开启隐藏路线与速通捷径，形成轻度类银河恶魔城结构。

**收集与叙事驱动**
- **记忆棱镜**：隐藏收集品，用于解锁背景设定、开发者注释、辅助模式（如无限体力、减速区域、跳过解谜）。
- **时空日志**：记录玩家最佳路线的“幽灵回放”，可叠加显示用于对比优化路线。
- **碎裂特效**：通过收集解锁不同材质的死亡碎裂效果（玻璃/冰晶/数据流/水墨），满足个性化表达。

**辅助与重玩价值**
- 内置“无障碍套件”：可独立开关（不成就锁定），确保休闲玩家体验完整流程，硬核玩家追求极限。
- 关卡评分系统：基于时间、死亡次数、收集率生成S/A/B/C评级，驱动重复挑战。

### 数值框架
- **属性体系**：本作摒弃传统HP/MP，采用“运动参数”体系：
  - `移动速度`（基础位移）
  - `跳跃初速`（决定起跳高度）
  - `重力系数`（影响下落加速度，受区域修正）
  - `冲刺距离/冷却`（爆发位移能力）
  - `空中控制力`（空中变向灵敏度）
  - `表面摩擦系数`（影响滑行/抓墙稳定性）

- **核心公式**：
  - `实际跳跃高度 = (初速²) / (2 × 基础重力 × 区域重力修正)`
  - `动量衰减 = 当前速度 × (1 - 空气阻力系数) × 帧间隔`
  - `关卡评分 = 基准分 × (1 - 死亡次数×0.05) × 连段加成(1+连续无失误跳跃×0.02) × 收集率修正`
  - *注：所有公式在编辑器中可视化可调，便于关卡策划快速迭代手感。*

- **平衡原则**：
  1. **失败即学习**：死亡无资源惩罚，仅消耗时间；残影机制将试错转化为解谜线索。
  2. **物理绝对透明**：所有区域规则、残影逻辑、输入窗口均通过视觉/音效明确提示，杜绝“黑箱难度”。
  3. **上限高、下限稳**：基础操作保证通关可行性，高阶技巧（动量拼接、残影连跳）提供速通与无伤空间。
  4. **动态难度不干预核心体验**：难度调节仅通过辅助选项实现，不改变关卡底层逻辑，保证排行榜公平性。

### 玩法亮点
1. **“失败资源化”设计**：传统平台跳跃的死亡是惩罚，本作通过“场景记忆”将死亡转化为路径标记、机关触发器或临时踏板。玩家越失败，关卡信息越完整，形成“试错-积累-突破”的正向心理循环。
2. **物理规则拼接交响**：动态重力/摩擦/弹跳区域并非孤立存在，而是要求玩家在动量守恒前提下进行“规则切换”。例如：利用零摩擦区加速 → 冲入低重力区滞空 → 切换重力反转完成倒挂跨越，形成高自由度的“跑酷编排”体验。
3. **碎裂美学与操作可视化**：角色移动留下的裂痕轨迹实时反映操作精度与路线选择；死亡时的华丽碎裂不仅是视觉反馈，更是“重置”与“记忆生成”的仪式感，强化紧张感与艺术表达的统一。
4. **心流节奏控制**：无缝重生+动态BPM配乐（随玩家移动速度/连段数自动调整节奏）+ 检查点智能分布，确保玩家在“专注-释放-再专注”的循环中保持沉浸，避免疲劳与挫败感堆积。
