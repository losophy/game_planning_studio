### 核心循环
**单局循环（1-3分钟）**：匹配/进入对局 → 战前技能卡组选择 → 轮流落子（普通棋子/技能棋子） → 触发技能效果/棋盘状态变更 → 实时胜负判定 → 结算奖励与高光回放生成 → 返回大厅。
**长期循环（赛季/周维度）**：对局积累资源 → 提升段位/解锁新技能棋子 → 构筑与调试个性化卡组 → 参与异步锦标赛/赛季活动 → 收集角色皮肤与成就 → 社交分享/观战复盘 → 策略精进与天梯冲分。
**循环设计逻辑**：以“极简操作+高频决策”降低上手门槛，以“技能构筑+卡组克制”提供策略深度。单局短平快保证碎片化体验，长期通过段位、锦标赛、收集与社交形成持续驱动力，有效对冲“单局过短易流失”的风险。

### 战斗/操作机制
**核心操作**：点击/拖拽落子。界面采用“棋盘区+手牌区+能量槽”三段式布局。玩家每回合拥有1点基础能量（上限3），普通落子消耗0能量，技能棋子消耗1-2能量。操作符合移动端直觉，支持“长按预览技能范围”与“撤销上一步（仅限练习模式）”。
**技能体系**：
- **分类**：干扰型（如“封锁”：相邻格下回合禁落）、进攻型（如“翻转”：将一枚敌方棋子转为己方）、防御型（如“护盾”：免疫一次技能效果）、特殊型（如“透视”：揭示对手手牌中随机一张技能）。
- **释放逻辑**：技能棋子以“暗牌”形式存在于手牌区，对手仅可见数量不可见类型。落子即触发，效果结算后该技能进入冷却（通常冷却1-2回合）或消耗完毕。
- **节奏控制**：引入“15秒思考倒计时”，超时自动落普通棋子。加入“战术暂停”（每局限1次，3秒），防止高压局误操作。
**AI与匹配**：基于MMR实时匹配。AI采用“模式识别+反制树”架构，低难度侧重基础连线教学，高难度模拟人类心理博弈（如故意留空诱导、技能虚晃）。

### 成长系统
**段位与天梯**：采用Glicko-2算法计算隐藏分，段位划分为青铜至宗师。赛季末按最高段位发放限定皮肤/头像框，段位重置保留部分继承分，保证冲分动力与新手保护。
**技能与卡组成长**：
- **精通度**：每枚技能棋子独立记录使用次数与胜率。达到阈值解锁“进阶词条”（如封锁范围+1格、翻转附带1点能量回复）。
- **卡组槽位**：账号等级解锁卡组预设位（初始3套，满级8套）。支持“一键分享卡组码”，促进社区策略流通。
**个性化与收集**：战斗通行证（免费/付费双轨）产出X/O角色皮肤、棋盘主题、胜利特效。成就系统绑定策略里程碑（如“首胜”、“三连翻盘”、“锦标赛八强”），提供叙事碎片与专属称号。
**异步锦标赛**：采用“报名-瑞士轮-淘汰赛”结构。每轮给予12小时响应窗口，支持“离线预设应对策略”。提供参赛券与保底奖励，降低参与门槛，完美契合碎片化场景。

### 数值框架
- **属性体系**：无传统RPG数值。核心指标为：`MMR`（匹配基准）、`卡组强度值`（战前平衡校验）、`技能胜率/选取率`（动态平衡监控）、`活跃度`（资源产出权重）。
- **核心公式**：
  - `MMR更新`：`ΔMMR = K × (实际得分 - 预期得分)`。K值动态浮动（新手40，宗师16），连败触发保护系数（0.8）。
  - `经济产出`：`金币 = 基础对局奖励 × (1 + 连胜系数×0.1) + 任务奖励 + 锦标赛名次系数`。
  - `技能平衡校验`：`单局卡组总强度 ≤ 阈值T`。通过蒙特卡洛模拟（10万次对局）验证各技能组合胜率方差控制在±3%内。
- **平衡原则**：
  1. **破局定式**：技能引入“非对称信息”与“状态覆盖”，打破经典井字棋最优解必平局的数学定式。
  2. **反制优先**：每个强效技能必须有明确的低成本反制路径（如“封锁”可被“远程落子”或“穿透技能”化解），杜绝无解Combo。
  3. **动态收敛**：避免滚雪球。技能效果多为一次性或短持续，确保棋盘状态每3-4步重置一次博弈重心，维持“易上手难精通”的张力。
  4. **数据驱动迭代**：每周监控技能选取率与胜率，采用“软调整”（修改冷却/消耗/触发条件）而非直接删除，保持环境流动性。

### 玩法亮点
1. **“动态棋盘”状态记忆**：技能落子后会在棋盘留下可视化痕迹（如焦痕、冰霜、符文），不仅改变当前局势，还为后续技能提供连锁触发条件，将静态3x3转化为动态策略沙盘。
2. **“心理博弈”手牌管理**：技能以暗牌形式存在，对手仅知数量不知类型。高阶玩家可通过“虚晃一枪”（假装保留强力技能实则消耗）诱导对手失误，将纯逻辑博弈升级为心理战。
3. **AI驱动的“一步封神”引擎**：基于决策树与胜率突变检测，自动抓取“陷阱布置”、“极限反杀”、“心理欺诈”等高光时刻，生成带战术解说的15秒短视频，内置一键分享模板，强化社交传播。
4. **异步锦标赛的“时间差策略”**：允许玩家在12小时内响应回合。引入“战术预设”功能（设置自动应对常见开局的脚本），兼顾休闲与竞技，解决实时匹配等待痛点。
5. **角色化情感包装**：“叉叉勇士”与“圈圈法师”拥有独立语音、性格表情与赛季微剧情。落子动画与技能特效深度绑定角色设定，让抽象符号具备IP生命力，提升收藏欲与情感连接。
