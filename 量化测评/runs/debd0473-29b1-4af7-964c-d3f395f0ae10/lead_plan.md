## 游戏概述
一款融合了Roguelike随机性与卡牌构筑策略性的游戏，玩家将在每次随机生成的冒险中构建独特的卡组，挑战不断变化的敌人与关卡，体验“每一次都是新开始”的乐趣。

## 核心定位
- **类型**：Roguelike卡牌构建游戏
- **平台**：建议PC（Steam）为主，移动端（iOS/Android）为辅
- **用户**：
  - 核心用户：喜欢《杀戮尖塔》、《怪物火车》等游戏的策略玩家
  - 扩展用户：对卡牌游戏感兴趣，但希望有更高重玩价值的玩家
  - 年龄层：18-35岁，偏好中等难度策略挑战

## 系统框架
```
游戏核心循环：
角色选择 → 关卡冒险（随机生成） → 卡牌战斗 → 奖励获取 → 卡组构建 → BOSS战 → 通关/失败

主要系统：
1. 战斗系统
   ├─ 卡牌战斗（回合制）
   ├─ 能量/资源管理
   └─ 敌人AI行为

2. 肉鸽系统
   ├─ 随机地图生成
   ├─ 随机事件/遭遇
   ├─ 永久死亡机制
   └─ 局外成长（可选）

3. 卡牌系统
   ├─ 卡牌获取（战斗奖励、商店购买、事件）
   ├─ 卡牌升级/移除
   ├─ 卡组构建策略
   └─ 流派/协同效应

4. 进度系统
   ├─ 成就/挑战
   ├─ 解锁内容（新角色、卡牌、遗物）
   └─ 数据统计
```

## 差异化设计
- **创新点**：
  1. **动态场景机制**：战斗场景不只是背景，而是可互动的元素（如可破坏的障碍物、随时间变化的环境效果）
  2. **双资源系统**：除了传统能量，引入“专注度”资源，影响卡牌效果强度，增加策略维度

- **记忆点**：
  1. **标志性角色设计**：每个可玩角色不仅能力不同，还有独特的剧情线和成长主题
  2. **“宿敌”系统**：每次运行中会随机生成一个特殊敌人，追踪玩家进度，增加叙事张力

## 开发建议
- **预估周期**：
  - MVP（最小可行产品）：6-8个月（1个角色，3个关卡区域，50张基础卡牌）
  - 完整版：12-18个月（3-4个角色，5个关卡区域，150+张卡牌，完整肉鸽系统）

- **关键风险**：
  1. **平衡性挑战**：肉鸽卡牌游戏的平衡需要大量迭代测试
  2. **内容消耗**：需要足够多的随机组合防止玩家快速耗尽内容
  3. **学习曲线**：需要设计友好的新手引导，避免吓退新玩家
