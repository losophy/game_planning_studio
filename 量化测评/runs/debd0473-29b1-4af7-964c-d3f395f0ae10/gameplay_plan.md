### 核心循环
**单次循环（局内体验）**
`选择角色 → 探索随机节点地图（战斗/事件/商店/休息/宿敌遭遇） → 卡牌对战（管理能量与专注度，互动场景元素） → 结算奖励（抽卡/升级/移除/获取遗物） → 优化卡组 → 区域BOSS战 → 进入下一区域/失败结算`
- **决策密度**：每场战斗前需根据当前“专注度阈值”、“场景状态”与“宿敌动向”调整出牌策略。
- **风险博弈**：高专注度带来爆发收益，但会吸引宿敌追踪或触发场景反噬；低专注度稳定但缺乏破局手段。

**长期循环（局外留存）**
`通关/失败 → 解锁新角色/基础卡池/遗物 → 完善“宿敌图鉴”与战术笔记 → 挑战更高难度/自定义规则 → 收集角色剧情碎片 → 解锁隐藏流派`
- **Meta驱动**：通过局外成长降低新手门槛（如解锁“初始专注护盾”），同时提供硬核玩家的“无限制挑战”与“速通路线”。
- **叙事牵引**：宿敌系统与角色剧情线绑定，每次失败/通关推进世界观碎片，形成“策略+叙事”双重复玩动力。

### 战斗/操作机制
**战斗类型**
回合制卡牌对战（玩家回合→敌人意图展示→玩家出牌→结算→敌人行动），支持PC键鼠/手柄与移动端触屏双端适配。

**核心操作**
- **双资源管理**：
  - `能量`：每回合固定恢复（基础3点），用于支付卡牌基础费用。
  - `专注度`：0-100动态计量条。通过特定卡牌、遗物或场景互动获取/消耗。专注度不直接用于支付，而是作为**效果放大器**与**状态触发器**。
- **场景互动**：每场战斗预设1-2个“战术地标”（如：掩体、元素池、机关）。玩家可使用带`[互动]`标签的卡牌或消耗1点能量+10专注度激活地标，改变战场规则（如：掩体提供3回合格挡，元素池使下一张火系卡牌伤害×1.5）。

**技能/卡牌体系**
- **卡牌分类**：攻击（直伤/多段）、技能（防御/控制/资源调度）、能力（持续光环/被动）、环境（触发地标/改变地形）。
- **专注阈值机制**：卡牌效果随专注度区间变化（例：`0-30`基础效果 / `31-70`附加穿透 / `71-100`触发连锁或形态转换）。鼓励玩家规划“蓄力-爆发”节奏。
- **操作优化**：支持拖拽排序、快捷施法、意图预览（高亮显示当前专注度下的卡牌实际效果），降低移动端操作负担。

**敌人与AI设计**
- **常规敌人**：意图驱动型AI，行动模式可预测但随区域难度叠加词缀（如“反伤”、“专注汲取”）。
- **宿敌系统**：每局随机生成1名追踪型宿敌。AI具备**动态学习**特性：记录玩家最近3场战斗的高频卡牌类型，在遭遇战中针对性调整抗性/打断技能。击败宿敌掉落专属“宿敌核心”（强力遗物/流派钥匙）。
- **难度曲线**：区域1（教学/基础机制）→ 区域2（专注阈值博弈）→ 区域3（场景联动+宿敌压制）→ BOSS（机制复合+多阶段）。

### 成长系统
**局内成长（单局构筑）**
- **卡牌获取**：战斗胜利三选一、事件抉择、商店购买。引入“流派倾向提示”（如高亮显示与当前卡组契合度>60%的卡牌）。
- **卡牌升级**：消耗金币提升基础数值或解锁“专注阈值分支”（例：升级后在71+专注时额外附加护盾）。
- **卡组精简**：付费移除低效卡，维持卡组循环效率。
- **遗物系统**：提供全局被动（如：每回合自动+5专注、场景互动费用减半、宿敌追踪延迟1节点）。

**局外成长（Meta进度）**
- **角色解锁**：通过通关/成就解锁新角色，每个角色自带专属“专注引擎”（如：狂战士“受击叠专注”、法师“专注自然衰减但技能倍率极高”、游侠“专注每回合重置但连击叠加”）。
- **宿敌图鉴**：记录遭遇过的宿敌行为模式与弱点，解锁后可在局外选择“宿敌预演”训练，或获得针对性开局加成。
- **难度与规则自定义**：通关后开放“突变词缀”、“专注上限调整”、“场景频率”等沙盒选项，满足硬核玩家。

**角色专属成长路径**
每个角色拥有独立的“专注天赋树”（局外解锁），提供3条分支：
1. `稳态流`：降低专注波动，提升基础卡牌稳定性
2. `爆发流`：加速专注积累，强化阈值上限效果
3. `环境流`：增强地标互动收益，解锁专属场景卡牌

### 数值框架
- **属性体系**：
  - `生命值(HP)`：生存核心，归零即败
  - `能量(Energy)`：每回合固定产出，决定出牌频率
  - `专注度(Focus)`：0-100动态值，影响卡牌倍率、状态持续时间、场景互动效率
  - `攻击/防御`：基础战斗数值，受卡牌与遗物修正
  - `场景亲和度`：隐藏属性，决定地标激活成功率与额外收益

- **核心公式**：
  - `实际伤害 = (卡牌基础伤害 + 角色加成) × (1 + 专注倍率系数) × 场景修正 - 目标防御`
  - `专注倍率系数 = 0.8 + (当前专注值 / 100) × 1.2`（线性平滑，避免阈值突变导致数值崩坏）
  - `专注获取/流失 = 基础值 × (1 + 遗物修正) ± 敌人词缀影响`
  - `商店价格 = 基础价 × (1 + 已购卡牌数 × 0.15) × 难度系数`
  - `升级费用 = 基础费用 × (1 + 当前等级 × 0.4)`

- **平衡原则**：
  1. **收益递减与风险对冲**：专注度越高，获取效率呈对数衰减；高专注卡牌附带“过载”副作用（如：下回合能量-1），防止无限滚雪球。
  2. **场景非强制**：地标互动为战术选项而非通关必选项，确保纯卡牌构筑流派同样可行。
  3. **宿敌克制透明化**：宿敌的针对性AI通过UI明确提示（如“该敌人对连击类卡牌抗性+50%”），将“挫败感”转化为“策略调整信号”。
  4. **新手保护曲线**：前3场战斗强制提供“专注引导卡”，前10次失败解锁局外“初始专注护盾”，平滑学习门槛。

### 玩法亮点
1. **双资源动态博弈**：打破传统“能量=出牌权”的单一逻辑，专注度作为“质量放大器”迫使玩家在“稳扎稳打”与“蓄力爆发”间做动态取舍，每回合决策维度翻倍。
2. **场景即战术棋盘**：地标不是背景贴图，而是可被卡牌“编程”的战场变量。玩家可通过环境卡牌改变地形、制造连锁反应，实现“以弱胜强”的非对称破局，大幅提升战斗记忆点。
3. **宿敌叙事压迫感**：宿敌不仅是数值挑战，更是“活着的对手”。它会学习、会追踪、会针对，击败后掉落专属核心，形成“遭遇-受挫-研究-反杀”的完整心流闭环，强化肉鸽的叙事张力。
4. **专注阈值流派分化**：同一张卡牌在低/中/高专注下呈现截然不同的战术定位（如：低专注为过牌工具，高专注为终结技），极大压缩卡组冗余，鼓励玩家围绕“专注节奏”构建高度协同的专属流派，保障百局不重样的策略深度。
