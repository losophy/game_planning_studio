## 项目规划方案

### 游戏概述
一款以“离线收益最大化”为核心体验的放置类游戏，玩家通过策略性配置资源，在离线期间持续获得丰厚回报，享受“不在线也能变强”的成就感。

### 核心定位
- **类型**：放置养成+轻度策略
- **平台**：移动端（iOS/Android）为主，可考虑PC端简化版
- **用户**：
  - 主要：20-35岁上班族，游戏时间碎片化
  - 次要：学生群体，喜欢低压力、持续成长的体验
  - 用户特征：追求效率、喜欢规划、享受“被动收入”带来的满足感

### 系统框架
```
核心循环：
离线收益 → 资源收集 → 升级配置 → 提高收益效率 → 再次离线

主要系统：
1. 收益系统（核心）
   ├─ 离线收益计算引擎
   ├─ 收益倍率机制
   └─ 收益上限管理

2. 养成系统
   ├─ 自动化单位（自动收集资源）
   ├─ 效率提升（升级、科技）
   └─ 特殊建筑（提供独特加成）

3. 策略配置系统
   ├─ 离线前资源分配
   ├─ 风险与回报选择
   └─ 多套配置方案保存

4. 社交系统（轻度）
   ├─ 收益排行榜
   ├─ 配置方案分享
   └─ 互助加成（好友间收益提升）

5. 目标系统
   ├─ 成就系统
   ├─ 阶段性目标
   └─ 赛季挑战（可选）
```

### 差异化设计
- **创新点**：
  1. **策略性离线配置**：玩家离线前需要精心分配资源、选择加成、设定目标，不同的配置策略会导致完全不同的离线收益结果
  2. **收益事件系统**：离线期间可能随机触发特殊事件（正面或负面），增加不确定性和重玩价值

- **记忆点**：
  - **“完美回归”时刻**：玩家上线时，通过华丽的动画展示离线期间的收益成果，创造强烈的正反馈
  - **配置对比功能**：系统自动记录不同配置方案的收益效率，帮助玩家优化策略

### 开发建议
- **预估周期**：
  - 原型阶段：2-3个月（完成核心收益引擎和基础UI）
  - Alpha版本：4-6个月（加入养成系统和基础内容）
  - Beta版本：3-4个月（平衡性调整、社交功能）
  - 总周期：9-13个月可上线1.0版本

- **关键风险**：
  1. **数值平衡**：离线收益数值需要精心设计，避免过快或过慢的成长曲线
  2. **玩家粘性**：放置类游戏容易在中期出现“登录疲劳”，需要设计有吸引力的中长期目标
  3. **付费设计**：如何在保障免费玩家体验的同时，设计合理的付费点（建议以“加速”和“便利性”为主，避免“付费变强”的强付费设计）

### 下一步建议
1. **明确目标平台**：优先考虑移动端，可快速验证核心玩法
2. **细化核心玩法**：需要确定离线收益的具体表现形式（数值增长、资源收集、单位生产等）
3. **确定美术风格**：建议采用简洁明快的2D美术风格，降低开发成本
