### 核心循环
**单次循环（单局体验，1-3分钟）**
`启动奔跑 → 观察前方障碍/道具 → 单指操作（点击/长按/滑动）规避或互动 → 触发连击/完美判定 → 结算分数与金币 → 失败/主动结束 → 领取奖励/观看广告复活（可选）`
- **节奏控制**：前30秒为适应期（基础障碍+教学提示），30-90秒进入心流期（动态障碍+连击叠加），90秒后进入高压期（速度提升+复合障碍+环境事件）。
- **即时反馈**：每次成功规避/互动触发屏幕震动、音效反馈与连击数跳动，维持多巴胺分泌。

**长期循环（留存与追求，天/周/月维度）**
`完成每日/周期挑战 → 积累金币/碎片 → 解锁角色/滑板/技能 → 提升基础属性与外观 → 冲击排行榜/赛季段位 → 参与限时活动 → 循环`
- **防枯燥设计**：引入“环境轮转”（晴天/雨天/夜间/磁暴）改变障碍生成逻辑与视觉风格；每周刷新“主题词缀”（如：滑铲收益翻倍、二段跳冷却缩短），强制改变单局策略。

### 战斗/操作机制
**核心操作（单指极简映射）**
- **点击（Tap）**：基础跳跃。支持**节奏判定**：在起跳瞬间的±0.15s内再次点击触发“二段跃”；在滞空顶点点击触发“滞空滑翔”（延长水平位移，用于跨越宽沟）。
- **长按（Hold）**：滑铲。长按时长决定滑铲距离（0.5s基础，1.2s极限）。长按期间角色受击判定框缩小，可穿过低矮障碍。
- **左右滑动（Swipe）**：三车道切换。滑动幅度需＞屏幕宽度的15%才触发，防误触。支持“滑动+点击”组合技：切道瞬间点击触发“侧翻跳”，用于规避侧面突进障碍。

**动态手势响应系统**
- **输入缓冲与容错**：设置0.1s输入缓冲窗口，避免网络/触控延迟导致操作丢失。
- **手感差异化**：根据点击位置（屏幕中下/中上）微调起跳角度；长按释放时机影响滑铲惯性。系统记录玩家操作习惯，动态微调判定阈值（隐藏式辅助，不破坏公平性）。

**环境互动式障碍设计**
- **闪烁型障碍**：出现前0.5s高亮闪烁。玩家可选择：①常规规避（安全）；②精准点击互动（高风险高回报）。互动成功转化为“能量球”（+连击/护盾/加速），失败则直接碰撞。
- **决策密度**：每局平均出现8-12次互动机会，强制玩家在“求稳保距离”与“激进刷分”间做微决策，打破纯反应类跑酷的单调性。

### 成长系统
**角色/技能成长路径**
- **角色特质（非数值碾压）**：每个角色携带1个被动特性与1个主动技能（冷却30s）。例：
  - `疾风跑者`：被动-滑铲距离+15%；主动-3s内移速提升20%。
  - `磁轨少女`：被动-金币吸附范围+30%；主动-生成临时护盾抵挡1次碰撞。
- **解锁与升级**：使用金币解锁角色，消耗“跑者徽章”（挑战模式产出）升级特性等级（上限Lv.5）。升级仅优化手感与容错，不突破核心数值上限。

**外观与收集系统**
- **滑板/轨迹/服饰**：纯视觉差异化，部分带微弱局内特效（如轨迹长度变化、落地火花）。通过赛季通行证、成就或限时活动获取。
- **图鉴与成就**：记录“完美规避次数”、“最高连击”、“互动转化成功率”等，提供长期收集目标。

**任务与挑战驱动**
- **每日/周常**：定向引导玩法（如“完成20次滞空滑翔”、“转化5个闪烁障碍”），奖励金币与徽章。
- **赛季通行证**：免费线提供基础货币与外观，付费线提供限定特效与角色。进度与单局表现挂钩，非强制付费。

### 数值框架
- **属性体系**：
  - `基础移速`：决定单局节奏与障碍刷新频率。
  - `连击衰减率`：无操作/碰撞后的连击归零时间（默认3s）。
  - `互动判定窗`：点击闪烁障碍的有效时间窗口（默认0.4s）。
  - `金币倍率`：影响局内经济产出。
  - `技能冷却/持续时间`：控制主动技能释放节奏。

- **核心公式**：
  - `单局得分 = 基础距离分 + (金币数 × 金币倍率) + (最高连击数 × 连击系数) + 互动转化奖励`
  - `移速曲线 = V(t) = V₀ + k·t + Σ(事件修正)` （k为固定加速度，t为时间，事件修正含天气/道具/技能。设置V_max封顶，避免后期失控）
  - `连击系数 = 1 + (当前连击数 × 0.08)` （连击＞50后衰减至0.05，防数值膨胀）
  - `经济产出 = 基础掉落率 × 移速修正 × 角色被动修正` （广告复活消耗随距离指数增长，限制无限刷分）

- **平衡原则**：
  1. **操作上限＞数值上限**：所有角色/道具的属性差异控制在±10%以内，高分核心依赖玩家操作精度与决策，而非付费堆砌。
  2. **风险收益对等**：互动障碍转化失败惩罚＞常规碰撞（如直接清空当前连击），但成功奖励为常规收集的3-5倍，鼓励高手进阶。
  3. **心流保护**：难度曲线采用“阶梯式+随机扰动”，每60秒提升一次基础移速，但通过环境事件（如短暂减速带、安全区）给予喘息窗口。广告/复活点严格限制在单局1-2次，避免打断单指操作流。

### 玩法亮点
1. **“节奏化跑酷”微创新**：将传统跑酷的“纯反应”升级为“节奏+决策”双核驱动。动态手势系统让单指操作具备类似音游的“Perfect判定”快感，配合震动与音效反馈，形成强烈的肌肉记忆与心流体验。
2. **互动障碍的“博弈矩阵”**：打破“见障就躲”的线性逻辑。闪烁障碍引入“风险-收益”微决策，配合连击系统，使单局体验从“机械重复”变为“动态策略选择”，有效解决休闲跑酷易枯燥的痛点。
3. **单手操作区极致优化**：屏幕中央60%区域为“黄金触控带”，UI全边缘化。结合输入缓冲、滑动防误触、长按惯性计算，确保通勤/地铁等颠簸环境下仍能稳定操作，真正落实“一键酷跑”的差异化定位。
4. **自适应难度与碎片化友好**：单局1-3分钟设计，支持随时暂停/退出。局外成长轻量化（无强制日常、无复杂养成），赛季词缀与环境轮转保证每次打开都有新鲜感，完美契合轻度玩家的碎片化节奏。
