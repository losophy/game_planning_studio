### 核心循环
**单次循环（局内行为流）**
准备生态工具/携带诱饵 → 进入探索区或农场地块 → 执行劳作（开垦/播种/浇水/采集）或触发环境互动 → 收获基础资源/触发“生态共鸣”事件 → 返回农场安置生物/分配工作/升级设施 → 结算收益并规划下一轮种植/探索路线。

**长期循环（留存与成长流）**
解锁新生态区域 → 收集/驯化奇幻生物 → 提升生物羁绊与特性解锁 → 构建“生态共生链”实现半自动化生产 → 完成小镇订单/达成图鉴里程碑 → 获取稀有种子/生态点数 → 解锁隐藏剧情/变异生物/高级设施 → 打造高复杂度、高收益的个性化生态农场。

**循环验证**
- 新手体验：前30分钟完成基础种植+引导生物契约，操作直观，正反馈密集（作物快速成熟、生物首次互动动画）。
- 中期目标：生态连锁反应显现，自动化产线初具规模，玩家从“手动劳作”转向“生态调度”，目标转为图鉴收集与区域探索。
- 长期追求：生态负荷管理与高阶共生搭配成为核心策略，多周目/沙盒模式提供“极限生态优化”与“全图鉴变异”挑战，维持长线动力。

### 战斗/操作机制
*注：本作无传统血条战斗，操作重心转向“探索交互”与“生态调度”。*

**核心操作**
- **双模控制**：PC端键鼠/手柄适配。左摇杆/WSAD移动，右摇杆/鼠标控制视角与工具轮盘切换（锄头、水壶、生态扫描仪、诱饵、指令板）。
- **环境交互**：长按/连击触发工具动作，支持“蓄力”提升单次作业范围或品质。生态扫描仪用于高亮显示地块属性、生物踪迹与隐藏资源。

**探索与驯化机制（替代传统战斗）**
- **生态共鸣系统**：遭遇野生生物时不进入战斗，而是进入“习性匹配”界面。玩家需根据生物提示（如：偏好湿度、光照、特定作物气味）投放对应资源，并跟随节奏完成“频率校准”小游戏。成功率受玩家生态知识等级与道具品质影响。
- **轻度冲突处理**：探索区存在“生态失衡”节点（如狂暴藤蔓、污染泥沼、掠夺性虫群）。玩家需派遣已契约生物，利用其特性进行“机制破解”（例：火系小龙灼烧藤蔓、水系花精净化污染、甲壳生物驱赶虫群）。无伤害数值对拼，侧重属性克制与技能释放时机。

**农场调度操作**
- **生态信标/指令板**：在农场划定工作区域，拖拽生物头像分配任务（专注浇水/施肥/巡逻/催熟）。支持设置优先级与轮班表，实现“一键托管”与“手动微调”无缝切换。

### 成长系统
**角色/农场成长**
- **农场等级**：通过完成订单、提升生态繁荣度升级。解锁新地块、设施槽位、温室/灌溉网络。
- **科技树**：分“基建”（工具效率、存储扩容）、“生态”（土壤改良、气候调节）、“自动化”（指令板升级、共生枢纽）三条分支，消耗金币与生态点数（EP）解锁。

**生物成长**
- **羁绊等级**：通过喂食、抚摸、完成工作时长提升。每级解锁新被动（如：浇水范围+10%、夜间生长加速）。
- **形态进化/变异**：当羁绊达到阈值且满足特定生态条件（如：连续3天处于高湿度+特定作物环绕），生物可进化为高阶形态或触发稀有变异（外观改变+特性分支）。
- **技能树**：进化后解锁2条特性分支（例：生产侧重/探索侧重），玩家可消耗EP重置或切换，适配不同农场阶段需求。

**生态网络成长**
- **共生羁绊**：特定生物组合放置相邻区域触发连锁加成（例：土拨鼠+花精=“沃土循环”，土壤肥力自动恢复+作物品质+15%）。
- **图鉴系统**：收集度解锁全局加成（如：全图鉴10%解锁“生态庇护”被动，降低极端天气影响）与隐藏探索区域入口。

### 数值框架
- **属性体系**：
  - **地块/作物**：生长周期、基础产量、品质系数、生态亲和度（决定吸引生物类型）。
  - **生物**：工作效率、能耗（饱食度/魔力值）、羁绊等级、特性覆盖率、生态负荷值。
  - **玩家**：体力/精力、工具熟练度、生态知识（影响驯化成功率、探索收益、配方解锁）。
- **核心公式**：
  - `实际产量 = 基础产量 × (1 + 品质系数) × (1 + 生态增益总和) × 随机波动(0.9~1.1)`
  - `生物工作效率 = 基础效率 × (1 + 羁绊加成) × 环境匹配度(0.5~1.5) - 疲劳衰减系数`
  - `生态负荷 = Σ(生物数量 × 负荷权重) / 地块承载力`。当负荷>1.0时，触发边际递减（效率下降、地块退化、需额外维护成本）。
- **平衡原则**：
  1. **自动化有上限，策略留空间**：生物提供“乘区加成”而非“完全替代”。高负荷会触发效率衰减与地块维护成本，保留玩家手动干预的高收益节点（如精准催熟、稀有杂交、生态事件响应）。
  2. **生态相克与互补**：增益非简单线性叠加，强依赖“环境匹配度”与“共生组合”。鼓励玩家研究搭配逻辑，而非无脑堆砌同种生物。
  3. **内容消耗控制**：生物获取采用“线索探索+生态条件满足+概率变异”三段式。图鉴进度与农场等级、区域解锁强绑定，拉长收集曲线；变异生物提供重复游玩价值，避免内容过早枯竭。
  4. **经济闭环**：金币用于基础基建与日常消耗；生态点数（EP）用于生物进化与高阶科技；稀有材料仅通过探索/事件产出，控制通胀，确保后期以“生态优化”替代纯数值堆砌。

### 玩法亮点
1. **“活体自动化”与“生态负荷”博弈**：打破传统种田游戏“挂机即毕业”的线性体验。引入生态承载力与边际递减机制，玩家需像经营真实生态园一样，动态平衡生物数量、种类与环境匹配度，形成“策略性自动化”而非“数值碾压”。
2. **动态生态演算系统**：地块属性非静态脚本。种植特定作物改变土壤pH/湿度，吸引对应生物；生物活动反哺地块（如发光菌类提升夜间生长，但过度聚集引发“光抑制”）。形成“观察环境→调整布局→优化产出”的闭环，赋予农场“呼吸感”。
3. **非暴力驯化与情感羁绊**：摒弃“战斗-捕捉”范式，采用“生态共鸣”与“习性满足”。生物具备独立AI与情绪反馈（如：心情好时主动帮忙，心情差时罢工或捣乱）。高羁绊解锁专属互动动画、隐藏剧情与变异路径，强化“宠物+员工”的双重情感投射。
4. **模块化共生产线**：支持玩家自由拼接生物特性，构建个性化生产链（例：土拨鼠松土 → 花精催芽 → 小龙控温 → 风精灵授粉）。提供“一键托管”与“手动微调”双模式，兼顾休闲玩家的轻松体验与硬核玩家的极限效率追求，完美契合目标用户画像。
