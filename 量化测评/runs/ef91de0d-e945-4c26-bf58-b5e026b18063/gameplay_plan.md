### 核心循环
**单次循环（单局体验流）**
`身份认知 → 昼夜交替行动 → 信息博弈/线索收集 → 推理辩论 → 投票/技能结算 → 黄昏身份流沙判定 → 阵营目标重置 → 循环至终局`
- **白天**：公开线索板交互、限时发言辩论、快捷表情/标记互动、分配投票权重。
- **黑夜**：秘密选择技能目标、消耗行动点、触发被动判定。
- **黄昏**：结算本轮行动，触发“身份流沙”条件判定，播放“逆转时刻”演出，更新阵营与胜利条件。
- **终局**：达成动态胜利条件或存活人数阈值，结算对局。

**长期循环（留存与社交驱动）**
`对局结算 → 获取推理经验/社交货币 → 解锁新角色/情景线索包/外观 → 提升个人社交画像等级 → 匹配同好/创建自定义房间 → 沉淀熟人社交关系`
- **循环验证**：
  - **新手体验**：基础局锁定“好人/坏人”二元身份，仅开放基础技能与固定流程，3局内完成核心规则教学。
  - **中期目标**：解锁“身份流沙”机制与情景线索，玩家追求“完美反转”与高演技评分，形成内容创作与分享动力。
  - **长期追求**：全角色精通、自定义房间规则搭建、社交画像标签收集（如“逻辑大师”“戏精”“流沙幸存者”），驱动UGC与社群活跃。

### 战斗/操作机制
*(注：社交推理类游戏的“战斗”本质为信息博弈与策略交互)*

**核心操作**
- **信息交互**：拖拽线索至公共线索板进行关联/质疑；长按语音发言时自动触发“发言计时器”与“逻辑高亮”辅助。
- **技能释放**：回合制策略卡牌式操作。选择技能 → 锁定目标/区域 → 确认消耗（行动点/冷却） → 结算生效。支持“预读条”与“反制打断”机制。
- **投票交互**：非简单1人1票。玩家可分配“信任筹码”（基础1票+额外筹码），支持“保命符”（免疫单次投票）与“弃权”策略。

**技能体系**
- **主动型**：消耗行动点释放（如“先知验人”、“魅惑者篡改线索”）。需预判目标心理，存在反制窗口。
- **被动型**：随身份/阵营状态自动生效（如“守护者”免疫首次流沙转换、“替罪羊”被投票时触发线索公开）。
- **触发型**：依赖特定条件激活（如“黄昏钟响”、“线索板关联度≥3”、“被连续怀疑2轮”）。
- **制衡设计**：技能形成“剪刀石头布”网状克制。例如：验人技能克制伪装者，但会被“线索篡改”干扰；篡改技能可被“逻辑锚点”技能识破并反噬。

**身份流沙交互**
- 黄昏阶段系统根据`信任差值`、`技能命中记录`、`情景线索触发`进行判定。
- 触发时进入3秒“逆转时刻”：全屏动态演出+音效，原角色技能树强制替换为流沙后身份技能，胜利条件实时更新并推送至个人UI。
- 转换后提供1轮“适应期”（额外行动点+线索提示），避免玩家因信息断层直接崩盘。

### 成长系统
**局内成长（动态资源流转）**
- **信任/怀疑值**：通过成功发言、技能命中、线索贡献累积。影响投票权重与流沙转换倾向。
- **行动点(AP)**：每轮固定刷新，技能消耗AP。局内可通过完成“情景任务”或触发特定线索临时获取。
- **线索权重**：玩家标记/分享的线索会累积“可信度”，高权重线索在辩论阶段自动置顶，低权重线索可被“质疑”技能清除。

**局外成长（Meta-Progression）**
- **角色解锁**：通过“记忆碎片”（对局结算产出）解锁新角色。每个角色附带专属背景故事、技能变体与流沙触发偏好。
- **社交画像**：系统记录`推理准确率`、`发言影响力`、`阵营胜率`、`流沙存活率`，生成动态标签。标签影响匹配池倾向与个人主页展示。
- **情景线索库**：收集不同主题线索包（古堡、赛博、民国等），支持房主自定义对局氛围与线索生成权重。
- **防数值膨胀**：所有局外成长仅解锁内容池、外观与匹配标签，**绝不直接加成单局属性**，确保竞技公平性。

### 数值框架
- **属性体系**：
  - `信任值(Trust)`：影响投票权重、流沙转换倾向、技能基础成功率。
  - `怀疑值(Suspicion)`：累积过高易被集火，但部分角色（如“替罪羊”“双面间谍”）需高怀疑值触发翻盘技能。
  - `行动力(AP)`：严格限制单轮技能释放频率，防止滚雪球。
  - `线索权重(Weight)`：决定线索在公共板的显示优先级与逻辑关联强度。

- **核心公式**：
  - `投票出局阈值 = ceil(存活玩家数 × 0.5) + Σ(信任筹码修正)`
  - `身份流沙触发判定 = (阵营信任差 ≥ 阈值A) ∨ (特定技能命中数 ≥ 阈值B) ∨ (黄昏随机池命中)` → 采用“确定性条件为主，小概率随机为辅”设计，确保策略可预判。
  - `技能基础成功率 = 基础值 × (1 ± 目标怀疑值修正) × (1 ± 环境线索修正) ± 反制技能惩罚`
  - `线索可信度衰减 = 初始权重 × e^(-质疑次数 × 衰减系数)`

- **平衡原则**：
  1. **动态重置**：身份流沙强制打破优势阵营的滚雪球趋势，劣势方通过转换获得新技能与目标，实现“非对称翻盘”。
  2. **信息透明化**：所有技能消耗、线索权重、投票筹码均公开可查，胜负取决于信息处理与心理博弈，而非隐藏数值。
  3. **反制窗口**：任何强力技能均存在1-2秒反制期或前置条件，避免“无解combo”。
  4. **可控随机**：情景线索与流沙触发遵循明确规则池，玩家可通过策略布局提高触发概率，杜绝纯RNG决定胜负。

### 玩法亮点
1. **“身份流沙”的戏剧张力设计**：转换非纯随机，而是基于玩家行为累积的“信任势能”。当信任链断裂或技能博弈达到临界点时触发，配合“逆转时刻”全屏演出，制造天然传播素材。转换后提供“适应期”与动态胜利条件，确保策略连续性而非断崖式挫败。
2. **情景线索的叙事推理层**：线索不仅是逻辑工具，更是角色扮演载体。真凶可利用线索“编造合理叙事”，好人需通过“线索关联度”与“发言逻辑一致性”拆解谎言。线索板支持拖拽连线，系统自动计算逻辑闭环强度，降低纯嘴炮局比例。
3. **社交画像驱动的精准匹配**：基于行为数据生成“硬核逻辑局”“戏精演绎局”“新手友好局”等标签池，玩家可一键匹配同好，大幅降低社交摩擦与压力。内置“情绪引导词库”与“一键举报/静音”机制，保障社区健康。
4. **渐进式学习曲线与复盘系统**：新手局逐步解锁机制（第1局基础身份→第3局开放技能→第5局开放流沙）。对局结束后提供“决策时间轴复盘”，高亮关键发言、技能命中、流沙触发点，支持一键生成短视频分享，兼顾教学与传播。
