### 核心循环
**单次循环**
进入关卡 → 自由探索/多视角观察 → 触发动态线索/收集交互物 → 逻辑推演/尝试组合 → 验证解法 → 触发“解法共鸣”反馈 → 结算奖励/解锁叙事碎片 → 返回主界面/进入下一关。

**长期循环**
主线关卡推进（机制解锁） → 追求多解法/隐藏收集（叙事拼图补全） → 挑战“反转关卡”与高难度变体 → 参与每日谜题/UGC社区 → 形成“探索-顿悟-分享-再探索”的留存飞轮。

**循环验证**
- 新手体验：前3关严格遵循“单机制教学→单机制应用→双机制融合”结构，3步内必给正反馈，零惩罚试错。
- 中期目标：动态线索与多解法系统叠加，玩家从“找答案”转向“找最优解”，收集系统与叙事碎片提供持续驱动力。
- 长期追求：全关卡“优雅解法”成就、隐藏叙事线完整度、每日谜题连胜、UGC关卡创作与游玩，解决纯内容消耗问题。

### 战斗/操作机制
*(注：解谜游戏以“交互/解谜机制”替代传统战斗)*

**核心操作**
- **移动端**：单指点击/拖拽交互物，双指缩放/旋转视角，滑动切换交互模式（如观察/操作）。采用“无UI沉浸”设计，交互反馈依赖物体高亮、物理震动、空间音效。
- **PC/主机**：键鼠/手柄全映射，支持视角平滑跟随与快捷键快速切换“交互透镜”。
- **软验证机制**：所有尝试即时反馈，失败仅局部重置（如机关归位、道具回弹），不扣资源、不读档，保障心流不断。

**动态线索系统**
线索采用“状态机”逻辑，非静态贴图。例如：
- **视角依赖**：移动摄像机至特定角度，光影投射形成隐藏图案或路径。
- **时序依赖**：触发A机关后，B物体表面浮现纹路，3秒后消失，要求玩家记忆与快速联动。
- **行为依赖**：玩家连续点击/拖拽某物体，其材质/形态发生渐变，暴露内部结构。

**提示系统**
三级递进提示（消耗“灵感值”）：
1. **观察引导**：高亮可交互区域或提示关键视角。
2. **逻辑指向**：指出关联元素或提示组合方向。
3. **步骤演示**：播放3秒解法动画（不跳过，仅演示）。
提示使用不阻断进度，但影响“优雅解法”判定。

### 成长系统
**认知与工具成长（非数值型）**
- **交互透镜解锁**：随主线推进获得特殊观察工具（如：热成像透镜看隐藏热源路径、声呐透镜听机关频率共振、逻辑滤镜高亮因果关联物）。每种透镜对应一类谜题，逐步叠加形成“解谜工具箱”。
- **机制熟练度**：通过重复使用特定机制（如光影折射、重力翻转），解锁该机制的“进阶变体”（如：折射可叠加两次、翻转可锁定局部区域）。

**收集与叙事成长**
- **碎片化叙事**：关卡环境、道具文档、隐藏彩蛋拼凑完整故事线。
- **多解法徽章**：每个关卡记录“标准解”“优雅解”“速通解”“隐藏解”，收集徽章解锁“开发者注释”或“平行关卡”（同场景不同初始条件）。

**长期追求**
- 全关卡“优雅解法”大师成就
- 叙事线100%收集
- 每日谜题连胜/UGC关卡创作与社区排行榜

### 数值框架
- **属性体系**：解谜游戏无传统战斗属性，转为“机制维度”量化：
  - `复杂度`：关联元素数量 × 逻辑链长度（决定单关信息处理负荷）
  - `容错率`：可尝试次数 / 局部重置成本（决定玩家试错压力）
  - `线索密度`：单位面积有效信息量 / 干扰信息量（决定观察难度）
  - `灵感值`：提示系统货币，局内自然产出+局外收集积累

- **核心公式**：
  - `难度系数 D = (逻辑链长度 L × 机制叠加数 M) / 线索可见度 V` （用于关卡难度标定与测试校准）
  - `优雅解法判定 E = (标准步骤数 S - 实际步骤数 A) × 环境利用率 U` （E≥阈值触发“解法共鸣”反馈）
  - `提示消耗 = 基础值 × (1 + 已用提示数)` （指数递增防滥用，保障核心循环不被破坏）

- **平衡原则**：
  1. **三阶递进与呼吸节奏**：单关遵循“教学-应用-变体”结构；全局难度呈阶梯上升，每5关设置“呼吸关”（低难度叙事/收集关），重置认知负荷。
  2. **多解法宽容与隐性降难**：不强制唯一路径；若玩家连续失败3次或频繁使用提示，系统自动触发隐性降难（如高亮关键关联物、延长机关响应时间、降低干扰项权重）。
  3. **动态线索可控性**：所有动态线索均遵循“可逆/可复现”原则，确保玩家能通过实验掌握规律，避免纯随机导致的挫败感。

### 玩法亮点
1. **“动态线索”状态机**：打破传统解谜“静态找物”逻辑，将线索与玩家行为（视角、位置、时序、交互频率）深度绑定，实现“所见即所得”的沉浸式推理，鼓励多角度实验。
2. **“解法共鸣”多轨反馈系统**：内置解法评估器，实时区分“标准解”与“优雅解”。优雅解不仅触发场景光效升级、BGM变奏，还可能解锁隐藏叙事或捷径，将“顿悟”快感具象化为视听与机制奖励。
3. **“认知反转”关卡设计**：中期引入“镜像逻辑关”，要求玩家用已学机制的逆运算破局（如：前期“光生影”找路径，中期“影遮光”破机关）。形成知识复用与认知颠覆的双重惊喜，强化玩家成长感知。
4. **心流保护与长效留存生态**：三级提示+隐性降难防流失；每日谜题+UGC编辑器+多解法收集系统解决内容消耗问题，构建“创作-挑战-分享”社区生态，延长游戏生命周期。
