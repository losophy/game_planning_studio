### 核心循环
**单次局内循环（单局战役）**
`侦察规划 → 部署站位 → 回合执行（移动/攻击/地形干涉/羁绊指令） → 结算反馈（地形改变/状态叠加/资源获取） → 推进节点 → 遭遇战/事件/休整 → 循环至关底BOSS → 撤离/结算`
- 玩家每回合通过分配行动点（AP）执行战术动作，重点在于利用地形改变创造优势或阻断敌人，并通过相邻站位触发羁绊指令打出爆发或控场。
- 局内通过击败敌人、探索隐藏区域、完成随机事件获取“战术印记”（局内临时强化）与“地形残片”（用于临时改变当前地图环境或兑换局外资源）。

**局外长期循环（Meta养成）**
`基地升级 → 角色解锁/技能树点亮 → 装备/遗物图鉴收集 → 剧情节点推进 → 开启新战役/难度 → 循环`
- 局外资源用于解锁新角色、升级基地设施（提供全局被动、初始羁绊等级、地形干涉工具等）、推进主线/支线剧情。
- 剧情与基地进度解锁新的“地形规则库”与“随机事件池”，确保Roguelike内容随进度动态扩展。

**循环验证**
- **新手体验**：提供“战术预演”模式（显示技能范围、地形改变结果、羁绊触发区），首局强制引导地形互动与基础羁绊，降低决策压力。
- **中期目标**：局内“战术印记”提供Build分支，局外基地提供永久解锁，形成“单局爽感+长期积累”的双轨驱动。
- **长期追求**：高难度挑战（如“地形灾变”模式）、全图鉴收集、羁绊全解锁、剧情多分支结局，配合赛季性主题更新维持内容新鲜度。

### 战斗/操作机制
**战斗类型**
半网格回合制战棋（支持自由微调站位，但核心判定基于网格/六边形混合逻辑，便于地形计算与AI寻路）。采用“行动点（AP）+ 回合阶段”制，每回合2AP，可移动+攻击，或双技能/地形操作。

**核心操作**
- **移动/站位**：消耗1AP，受地形高度、障碍、元素表面影响移动力。
- **攻击/技能**：消耗1AP，受武器类型、技能冷却、AP限制。
- **地形干涉**：专属技能或通用道具，消耗1AP或特定资源，永久改变网格属性（如：炸毁掩体、铺设导电水面、升起冰墙、制造毒沼）。
- **羁绊指令**：当2-3名特定角色处于相邻/连线站位时，消耗共享AP或触发“共鸣槽”，释放联合技（如：交叉火力、元素反应链、护盾转移）。
- **结束回合**：切换至敌方阶段，敌方AI执行行动。

**技能体系**
- **分类**：单体/范围/地形干涉/支援/羁绊专属。
- **释放方式**：AP消耗制，部分技能附带“地形亲和”加成（如：火系技能在干燥草地伤害+30%，在水面产生蒸汽遮蔽）。
- **组合效果**：技能与地形、状态、羁绊形成乘区叠加。例如：先制造“导电水面”→再释放“雷击”→触发“麻痹”→相邻队友触发“雷暴共鸣”追加AOE。

**敌人AI设计**
- **行为逻辑**：基于“威胁评估+地形利用”双权重。优先攻击高威胁目标，主动利用/破坏地形（如：远程敌人优先占据高地，近战敌人会尝试填平沟壑）。
- **难度曲线**：普通敌人行为可预测（固定技能池）；精英敌人具备“地形反制”能力（如：生成反伤荆棘、修复桥梁）；BOSS拥有“阶段地形重构”机制（半血后改变战场规则）。
- **节奏控制**：敌方回合采用“批量结算+关键动作特写”压缩等待时间，保持战棋节奏紧凑。

### 成长系统
**局内Roguelike成长（单局）**
- **战术印记**：击败敌人/探索获取，提供临时属性加成、技能变异、地形干涉强化。采用“三选一”分支，鼓励Build构建。
- **遗物/装备**：局内拾取，提供机制级改变（如：移动后不消耗AP、羁绊指令范围+1格、地形改变附带额外状态）。
- **羁绊共鸣等级**：局内通过相邻作战次数提升，解锁更强羁绊指令或降低触发门槛。

**局外Meta养成（永久）**
- **角色养成**：基础等级提升属性上限；技能树解锁新技能分支与被动；专属装备槽提供局外固定加成。
- **基地建设**：设施升级提供全局增益（如：战术预演时间延长、初始AP+1、地形干涉道具携带上限提升、特定元素抗性提升）。
- **剧情与阵营**：推进主线解锁新角色、新战役主题、新地形规则库；阵营声望影响商店折扣与特殊事件触发率。

**羁绊与小队协同成长**
- 羁绊系统独立于角色等级，通过“共同出战次数”与“局外羁绊任务”提升。
- 高羁绊等级解锁“战术阵型”（开局预设站位加成）、“羁绊专属被动”（如：相邻时共享护盾、受伤时触发反击）、“终极共鸣技”（需满足特定站位与资源条件）。

### 数值框架
- **属性体系**：
  - `HP`：生命值，归零退场。
  - `AP`：行动点，决定单回合操作上限。
  - `ATK/DEF`：基础攻防，受装备与等级影响。
  - `SPD/先攻`：决定回合内出手顺序与闪避阈值。
  - `地形亲和`：角色对特定地形（火/冰/雷/毒/高地/掩体）的伤害修正与抗性。
  - `共鸣值`：羁绊指令充能资源，受站位与技能联动影响。
- **核心公式**：
  - `最终伤害 = (基础ATK × 技能倍率 × 元素/地形修正 × 暴击修正) - (目标DEF × 减伤系数)`
  - `地形修正 = 1 + Σ(地形类型加成) × 角色地形亲和系数`（支持乘区叠加，上限1.8防数值膨胀）
  - `经验/资源获取 = 基础值 × (1 + 难度系数) × 局内印记加成`
  - `经济循环`：局内“战术印记”仅单局有效；局外“蓝图/残片”用于基地升级与角色解锁，采用软上限设计（后期获取效率递减，转向收集与外观）。
- **平衡原则**：
  1. **地形权重 > 数值碾压**：地形改变带来的战术优势应显著高于单纯堆叠ATK/DEF，鼓励“智取”而非“硬刚”。
  2. **站位即资源**：羁绊触发依赖站位，但不过度惩罚移动；提供“位移补偿”机制（如：部分技能可附带短距位移）。
  3. **可预测的随机性**：Roguelike事件与掉落采用“伪随机+保底”机制，确保单局体验不崩盘，Build路径清晰。
  4. **软性数值天花板**：局外养成提供便利性与容错，但不破坏单局策略核心；高难度下局外加成衰减，回归纯策略博弈。

### 玩法亮点
1. **“地形雕刻”动态博弈层**
   地形不仅是掩体，更是可塑资源。玩家可主动“造桥渡河”、“炸墙开路”、“引水导电”，敌人也会“填平陷阱”、“点燃草地”。战场随回合推进持续演变，形成“开局定策略，中局改地形，终局拼执行”的立体决策链。

2. **“站位即资源”的羁绊指令**
   摒弃传统“攒能量放技能”的线性逻辑，将“相邻/特定阵型”作为核心资源。羁绊指令不消耗独立CD，而是共享AP或共鸣槽，强制玩家在“单兵输出”与“团队联动”间做取舍。高羁绊角色可形成“战术核心”，带动全队Build。

3. **“策略回放引擎”终局结算**
   内置关键帧追踪系统，自动记录本局中“地形改变阈值突破”、“羁绊连击触发”、“残局翻盘”等高光时刻。结算时以电影化分镜+动态数据面板回放，支持一键生成短视频/动图。不仅强化成就感，更天然契合社区传播与二创生态。

4. **针对开发风险的机制化解**
   - **上手难度**：提供“战术沙盘”预演、一键高亮羁绊触发区、地形改变结果预览；难度梯度通过“AI行为透明度”与“容错机制（如：首局免死）”平滑过渡。
   - **内容消耗**：采用“规则库+模块化事件”生成逻辑。地形规则、敌人行为、事件标签可自由组合，配合关卡编辑器实现“种子生成+人工精调”，大幅降低内容管线压力。
   - **性能表现**：地形改变采用“网格状态机+LOD分层渲染”，仅对玩家视野内网格进行高精度物理/粒子计算；终局回放采用“预烘焙关键帧+轻量级插值”，避免实时演算卡顿。
