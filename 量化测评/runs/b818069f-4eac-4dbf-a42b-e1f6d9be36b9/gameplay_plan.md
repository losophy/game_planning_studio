### 核心循环
**单局行为流**：快速匹配/建房 → 规则预览（含沙盒/融合提示） → 30秒自适应引导 → 核心游玩（1-3分钟/局） → 动态结算（积分/排名） → “社死回放”自动生成 → 一键分享/点赞 → 返回大厅/进入下一轮
**长期留存循环**：对局积累“派对币/经验” → 解锁外观/称号/贴纸/回放滤镜 → 赛季通行证/主题周活动 → 解锁沙盒规则预设/自定义房间权限 → 社交分享裂变 → 持续游玩新小游戏/挑战好友记录

### 战斗/操作机制
**统一输入抽象层**：采用“双键+单摇杆/方向键”极简映射。平台适配：PC/主机（左摇杆移动，A键交互/跳跃，B键特殊/道具），移动端（左侧虚拟摇杆，右侧双大按钮+滑动触发）。输入做归一化处理，确保跨平台公平性。
**情境化操作（Context-Sensitive）**：根据当前小游戏类型动态切换按键功能。例如：竞速类中A键为“冲刺/跳跃”，B键为“干扰/道具”；节奏类中A/B键转化为“节拍判定”；物理类中长按B键触发“抓取/投掷”。
**网络与物理同步策略**：采用“客户端预测+服务器状态校验”的轻量级架构。物理交互采用“确定性回放+宽容判定框”，允许0.1-0.2秒的输入延迟补偿，优先保障“操作跟手感”与“搞笑反馈”而非绝对精度。

### 成长系统
**局外成长（无数值碾压）**：纯外观与社交驱动。通过“派对等级”解锁角色皮肤、表情动作、UI主题、回放滤镜及“规则沙盒”高级预设槽位。
**小游戏精通系统**：每个小游戏独立记录“个人最佳/历史排名”。达成特定条件（如“连续3局第一”“完美躲避10次”）解锁专属称号与动态贴纸，满足收集欲与炫耀需求。
**社交资产沉淀**：建立“派对相册”与“高光时刻库”。玩家可对他人分享的回放进行“点赞/吐槽”，积累“人气值”兑换限定外观。支持创建“固定车队”，车队共享专属房间背景与匹配优先权。

### 数值框架
- **属性体系**：
  - **局内状态**：活力值（用于释放特殊动作/道具，自动回复）、混乱度（沙盒/融合模式专属，随时间或互动累积，触发随机事件）、得分系数（基于操作精度、连击、风格化动作动态浮动）。
  - **局外资产**：派对经验（升级通行证/等级）、派对币（购买外观/滤镜）、人气值（社交互动产出）。
- **核心公式**：
  - **单局得分** = `基础完成分 × (1 + 时间加成系数) × 风格乘数(0.8~1.5) + 互动加分(干扰/救援/搞笑判定)`
  - **经济产出** = `对局基础币 × (1 + 排名权重) + 成就/赛季加成`。消耗端采用“保底+随机”外观池，确保非付费玩家30小时内可解锁基础全套。
  - **动态平衡（橡皮筋机制）**：落后玩家获得`速度/判定宽容度 × (1 + 落后差距系数)`的隐性补偿，确保最后10秒仍有翻盘可能，维持全员参与感。
- **平衡原则**：
  - **趣味优先，公平兜底**：允许非对称设计（如道具强弱差异），但通过“随机刷新”与“橡皮筋机制”防止滚雪球。
  - **输入宽容，反馈放大**：判定框扩大15%-20%，失败动画夸张化（如慢动作+音效），将“挫败感”转化为“节目效果”。
  - **沙盒规则互斥与代价**：房主微调规则需遵循“收益-风险”对等（如“低重力”提升跳跃高度但降低移动控制精度），避免规则组合导致游戏崩溃或单边碾压。

### 玩法亮点
1. **“规则沙盒”可视化配置器**：房主开局前通过拖拽“规则卡牌”（如：反向操作、重力异常、胜利条件反转、道具倍率）进行组合。系统实时预览规则冲突并给出“混乱指数”评级，高指数局额外奖励“混乱币”，鼓励玩家尝试极端玩法。
2. **“混乱融合”动态事件轴**：在标准小游戏流程中嵌入“融合节点”。例如“节奏大乱斗”进行到60%时，场景突然切换为“物理躲避球”模式，背景BPM与球体生成频率同步。系统通过强视觉/听觉提示（屏幕震动+节拍闪光）平滑过渡，制造“意料之外、情理之中”的惊喜感。
3. **AI驱动的“社死回放”引擎**：内置行为捕捉算法，实时标记“高动量碰撞”“连续失误”“极限反杀”“滑稽物理反馈”等事件。结算时自动剪辑3-5秒短视频，叠加动态字幕、 meme音效与平台适配滤镜。支持一键生成“朋友圈/抖音/小红书”竖版格式，附带游戏内二维码引流，形成自传播闭环。
4. **跨平台“无缝派对”体验**：采用“房间码+一键入队”机制，支持PC/主机/手机混合匹配。输入设备自动识别并匹配对应UI提示，语音聊天内置“变声器/搞笑音效”快捷触发，强化“数字破冰”定位，降低社交门槛。
