### 核心循环
**单次循环（微观体验）**
阅读情境文本 → 识别决策节点 → 评估选项代价/收益（结合已知线索、角色关系与世界状态） → 做出选择 → 触发即时反馈（文本变化/NPC态度转变/隐藏标记更新） → 推进至下一叙事节点。

**长期循环（宏观留存）**
完成单周目主线 → 解锁“蝴蝶效应”回溯界面与隐藏档案 → 开启多周目（New Game+） → 携带“认知记忆”或“关键执念”进入新开局 → 利用信息差做出差异化选择 → 收集全分支结局/补全世界观拼图。

**循环验证**
- 新手体验：开局采用线性引导+低压力选项，部分选项附带轻量提示（如“此选择将影响XX的信任”），降低决策焦虑。
- 中期目标：关系网与阵营倾向逐渐成型，关键抉择产生连锁反应，玩家从“被动阅读”转向“主动规划路线”。
- 长期追求：全结局收集、隐藏剧情解锁、道德倾向成就，以及“蝴蝶效应”图谱的完整点亮与多周目路线探索。

### 战斗/操作机制
*(注：针对文字冒险类型，将“战斗/操作”转化为“交互与抉择机制”)*

**核心操作方式**
- 基础交互：点击/滑动推进文本，长按查看“线索/设定”悬浮窗。
- 决策面板：在关键节点弹出选项界面，提供2-4个显性选项。部分选项需满足特定条件（如`洞察≥3`、`与A关系为敌对`、`持有关键道具`）才会解锁或高亮显示。
- 隐性操作：支持“沉默/不回应”、“语气微调”、“物品交互”等低干预操作，系统后台记录倾向值，不立即触发分支，但累积影响后续NPC态度或隐藏事件触发率。

**抉择系统设计**
- **动态权重刷新**：选项并非静态写死，而是根据当前`关系值`、`阵营倾向`、`已知情报`实时生成。例如：若玩家前期多次协助某阵营，该阵营NPC会在后续危机中提供专属救援选项。
- **限时/深思抉择**：常规节点无时间压力；重大道德冲突节点可开启“倒计时”或“环境音效压迫”模式，强化沉浸感与抉择重量。
- **状态快照与回溯**：提供“关键节点存档”功能，允许玩家回退至最近分支点重选。系统会记录历史选择路径，用于后续“蝴蝶效应”可视化展示。

### 成长系统
**角色/关系成长（无传统等级）**
- **羁绊维度**：针对核心NPC设置`信任/敬畏/敌意/利用`四维倾向。通过选择累积点数，突破阈值（如±50）触发“质变事件”（结盟/决裂/专属支线），并永久改变该NPC的对话库与行为逻辑。
- **认知/洞察成长**：玩家通过探索收集“线索碎片”、“记忆残片”或“文献”，提升`世界认知度`。认知度越高，可解锁的深层选项越多，能看穿NPC谎言、发现隐藏路径或触发真结局前置条件。

**叙事/元成长（Meta-Progression）**
- **记忆继承（New Game+）**：多周目保留`认知度`与`关键抉择记忆`。玩家可携带特定“预知”或“执念”进入新周目，改变初始关系基线或解锁隐藏对话树。
- **档案/图鉴系统**：收集角色背景、世界设定、分支节点记录。完成度奖励为纯叙事补充（如额外信件、设定集、UI主题），不破坏核心剧情平衡。

### 数值框架
- **属性体系**：
  - `关系值(Relation)`：针对主要NPC，范围-100~100。决定对话态度、选项解锁、剧情援助。
  - `阵营倾向(Faction)`：0~100。影响世界状态、可用路线、敌对/友方NPC刷新。
  - `道德/理智(Morality/Sanity)`：隐藏变量，影响特定文本渲染风格、结局分支走向及NPC极端行为触发。
  - `认知度(Insight)`：0~50。决定信息获取量、隐藏选项可见性、谎言识破率。
  - `状态标记(Flags)`：布尔值或计数器，记录关键事件（如`Met_The_Stranger=True`、`Stole_Key=1`）。

- **核心公式**：
  - **选项解锁判定**：`IsUnlocked = (Current_Insight >= Req_Insight) AND (Relation_Target >= Req_Relation) AND (Flag_Event == True)`
  - **动态文本调用**：`Text_Output = Base_Template + Weight(Relation, Faction, Morality)`。根据变量区间匹配不同文本块（例：信任>50时NPC主动提供情报；敌意>50时NPC设下陷阱或沉默）。
  - **成长曲线**：采用阶梯式阈值设计。关系值在-30~30区间变化平缓（日常交互），突破±50时触发“剧情质变”，避免数值通胀导致分支失控。

- **平衡原则**：
  1. **收敛设计（Convergence）**：采用“分支-汇聚”结构。关键分歧点提供差异化体验，但在重要剧情节点（Checkpoint）强制汇聚，严格控制内容量爆炸。
  2. **变量驱动替代纯分支**：用隐藏变量状态改变同一段剧情的演出/对话/结果，而非为每个选择编写全新剧本。实现“指数级叙事可能性，线性级开发成本”。
  3. **代价明确化**：重大选择附带明确提示（如“此选择将永久关闭XX路线”或“XX阵营将转为敌对”），确保玩家理解抉择重量，避免盲目试错。

### 玩法亮点
1. **“蝴蝶效应”可视化图谱**：游戏内置动态流程图系统。通关后或关键节点可解锁，高亮显示玩家的关键抉择如何像多米诺骨牌一样影响后续事件、NPC命运与世界状态。提供极强的叙事反馈与多周目重玩动力。
2. **动态语境选项（Context-Aware Choices）**：决策面板不再是静态的A/B/C，而是根据当前关系、已知情报、甚至玩家之前的“沉默”或“物品持有”状态实时演算生成。让每次游玩的决策体验独一无二。
3. **道德灰度与“代价”系统**：摒弃非黑即白的善恶值。每个重大选择都有明确的“获得”与“失去”。系统会量化提示潜在后果，强化“你的故事，你书写”的核心主题，让玩家在深度思考中承担叙事责任。
4. **防内容爆炸的“变量叙事”架构**：基于Ink/Twine等引擎的变量替换技术，同一场景根据隐藏变量组合输出不同对话、演出与结果。用“状态矩阵”替代“线性分支树”，在控制开发周期与测试复杂度的同时，实现高自由度的叙事深度。
