### 核心循环
**单局循环（微观体验）**
1. **起手调度**：根据手牌与初始战场格分布，决定留牌策略（如保留地形改造卡或核心羁绊组件）。
2. **费用规划与落位**：每回合获得递增法力水晶，玩家拖拽卡牌至棋盘。落位需结合当前地形效果（如将高血量单位置于“圣泉”格，或将低费铺场卡置于“燃烧之地”格触发亡语）。
3. **羁绊判定与结算**：系统实时检测同回合/相邻回合打出的羁绊卡牌，触发专属连携效果（如属性叠加、额外法术、召唤物协同）。
4. **战场演变**：回合结束时，系统刷新1-2个新地形格，玩家卡牌的“改变地形”效果生效，为下一回合布局埋下伏笔。
5. **胜负判定**：通过单位交换、法术直伤或特殊胜利条件击败对手，结算对局奖励。

**长期循环（宏观留存）**
对局（PvP/PvE） → 获取金币/粉尘/赛季积分 → 解锁卡包/合成目标卡牌 → 使用“羁绊分析器”与“地形模拟器”优化卡组 → 天梯冲分/解锁PvE章节/完成赛季任务 → 获取限定外观/称号/新机制卡牌 → 持续迭代构筑策略。

### 战斗/操作机制
**战斗类型**
回合制卡牌对战（移动端优先，采用拖拽+点击确认的交互逻辑，PC端支持键鼠快捷操作）。

**核心操作**
- **拖拽落位**：卡牌从手牌区拖至3×3共享棋盘。落位瞬间显示地形预览（如“若置于燃烧格，本回合结束时受到2点伤害”）。
- **目标指定**：法术/指向性技能通过点击敌方单位、友方单位或空格释放。
- **羁绊时机确认**：当手牌或已打出卡牌满足羁绊条件时，卡牌边缘高亮并显示“羁绊就绪”提示。玩家可选择立即触发或延迟至下回合（部分羁绊支持蓄力）。
- **地形干预**：部分卡牌带有“改造”标签，打出后可覆盖或改变指定格子的地形属性，实现战术反制。

**战斗节奏设计**
- 前3回合：侧重手牌管理与地形试探，节奏较慢。
- 4-6回合：费用充足，羁绊触发频率上升，地形争夺白热化，进入战术爆发期。
- 7回合后：资源见底，依赖地形残局处理与羁绊终结技，强调决策精度。

### 成长系统
**卡牌与构筑成长**
- **收集维度**：通过卡包、赛季通行证、PvE冒险、分解合成获取卡牌。卡牌分为普通/稀有/史诗/传说，稀有度仅影响获取难度与美术特效，不直接破坏平衡。
- **构筑工具**：内置“羁绊链路图”（可视化展示卡牌间的潜在连携）与“地形策略沙盘”（模拟不同卡组在随机地形下的胜率分布），降低试错成本。
- **熟练度系统**：单张卡牌/卡组使用次数累积“熟练度”，解锁专属卡背、动态边框、羁绊演出皮肤等纯外观奖励，避免数值膨胀。

**账号与内容成长**
- **PvE冒险模式**：以“地形解谜”与“羁绊试炼”为核心，逐步解锁新机制、背景故事与固定奖励卡牌。难度曲线平滑，承担新手教学与机制验证功能。
- **赛季/天梯**：每赛季引入1-2张新机制卡或微调地形池，保持Meta新鲜度。段位奖励侧重外观与社交展示。

### 数值框架
- **属性体系**：
  - `费用`：决定卡牌打出门槛，遵循标准法力曲线（1~10费）。
  - `攻击/生命`：基础攻防面板，决定单位交换效率。
  - `速度`：决定同回合内多张卡牌/羁绊的结算优先级（高速先结算）。
  - `地形亲和`：隐藏属性，影响单位在特定地形上的增益/抗性系数（如“火系亲和”在燃烧格伤害+15%，受灼烧伤害-20%）。

- **核心公式**：
  - `实际伤害 = (基础攻击 × 地形修正系数) - 护甲/减伤`
  - `羁绊加成 = 基础效果值 × (1 + 羁绊协同系数 × 触发卡牌数量)`（设置硬性上限，防止指数爆炸）
  - `经济产出 = 基础金币 × (1 + 对局时长系数 + 连胜/表现系数) + 赛季任务固定奖励`
  - `卡包保底 = 每10包必出1张史诗，每40包必出1张传说`

- **平衡原则**：
  1. **地形可控化**：随机地形仅占棋盘30%，剩余70%可通过卡牌干预或自然衰减。确保“运气不决定胜负，决策决定上限”。
  2. **羁绊非强制**：羁绊提供战术爆发点，但单卡独立强度必须达标。禁止“无羁绊即废卡”的设计。
  3. **费用效率守恒**：高费/高羁绊卡牌需承担更高风险（如延迟生效、地形依赖），维持“节奏/控制/组合技”铁三角平衡。
  4. **移动端适配**：单局时长控制在8-12分钟，费用增长与抽牌速率严格匹配移动端碎片化体验。

### 玩法亮点
1. **棋盘即资源，落位即博弈**：打破传统CCG“纯手牌管理”的局限，将策略维度延伸至空间占位。玩家需像下棋一样预判地形刷新、规划单位阵型，形成“手牌+棋盘”双轨决策，大幅提升单局重玩价值。
2. **羁绊叙事化演出，策略与IP深度绑定**：羁绊不仅是数值叠加，更是世界观的延伸。触发时播放专属动态分镜与语音（如“双生法师”共鸣、“古龙与祭司”召唤仪式），让构筑过程充满收集与探索的仪式感，精准击中IP/美术向玩家。
3. **动态难度自适应引导**：针对“学习曲线陡峭”风险，PvE模式采用“地形解谜关卡”逐步教学（如强制玩家利用圣泉格存活、利用燃烧格清场）。天梯匹配初期提供“羁绊推荐卡组”与“地形提示开关”，实现低门槛入坑、高上限精通。
4. **反同质化Meta设计**：传统CCG易陷入“最优解卡组”固化，本作的“随机地形+羁绊组合”天然抑制固定套路。每局地图不同，迫使玩家动态调整出牌顺序与落位策略，让“随机应变”真正成为核心乐趣而非干扰项。
