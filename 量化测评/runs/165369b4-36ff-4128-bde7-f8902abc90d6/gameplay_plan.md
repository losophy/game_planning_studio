### 核心循环
**单次局内循环（单局体验流）**
`开局选模 → 滑动落子 → 触发合并/连锁 → 结算资源/分数 → 触发里程碑事件 → 三选一构筑（规则/技能/棋盘） → 空间管理/应对障碍 → 达成目标或棋盘满格终局 → 局内结算`

**长期局外循环（留存与成长流）**
`完成对局 → 获取星尘/金币 → 解锁新主题/初始模组/被动天赋 → 填充“数字进化”图鉴 → 挑战更高难度/无尽模式 → 验证新构筑策略 → 循环`

**循环验证**
- **新手体验**：首局强制使用“经典2048规则+基础4x4棋盘”，通过3步引导完成滑动与合并，5分钟内体验首次“数字进化”动画，确保零门槛上手。
- **中期目标**：每合成3次或分数达到阈值触发“规则抉择”，提供明确的短期正反馈；特殊地形与技能释放形成“破局-压制”节奏，维持心流。
- **长期追求**：图鉴收集（108种主题形态）、规则模组全解锁、无尽模式排行榜、隐藏成就（如“质数大师”、“连锁狂人”），提供可持续的探索与炫耀目标。

### 战斗/操作机制
*(注：此处“战斗”指代核心解谜博弈与棋盘控制机制)*

**核心操作**
- **四向滑动**：玩家上/下/左/右滑动，所有数字沿滑动方向移动至边界或相邻数字处。相同数字碰撞合并，不同数字堆叠阻挡。
- **重力与吸附**：合并后产生空位，上方/侧方数字受重力自然下落填补，保证棋盘始终处于动态可操作状态。
- **技能交互**：长按/点击技能图标释放局内能力（如：炸弹清除3x3区域、悔棋回退1步、冻结指定格10秒不生成新数字），消耗局内资源。

**规则模组交互（动态合并逻辑）**
- 模组作为“被动底层逻辑”实时运行。例如激活【质数法则】时，系统拦截所有“质数+质数”的合并请求，仅允许“质数+1”或“质数+合数”触发；激活【斐波那契链】时，相邻的1,1,2,3,5可触发跨格连锁合并。
- 规则冲突处理：采用“优先级队列”机制（特殊公式 > 连锁反应 > 基础相加），避免逻辑死锁。

**棋盘生态与障碍**
- **传送门格**：数字滑入A口，从B口滑出，用于打破空间僵局。
- **固化格/冰层**：占据格子且不可合并，需通过相邻合并2次或使用道具击碎。
- **倍率格**：数字滑入后合并得分×2，鼓励路线规划。

**操作节奏控制**
- 前期：高频合并，快速积累资源与空间。
- 中期：节奏放缓，侧重路线规划、技能时机与规则协同。
- 后期：高压生存，依赖连锁爆发与精准操作破局。

### 成长系统
**局内Roguelike构筑（单局策略流）**
- **触发节点**：每达成指定分数/合并次数/清除障碍数，弹出“三选一”界面。
- **构筑维度**：
  1. **规则模组**：改变合并底层逻辑（如：偶数优先合并、合成产出金币、相邻同色数字自动吸引）。
  2. **主动技能**：一次性或冷却制能力（炸弹、洗牌、指定格生成2/4、时间缓流）。
  3. **棋盘扩展**：临时增加1行/1列、解锁传送门、将1个固化格转化为倍率格。
- **叠加机制**：同类规则可叠加但存在“冲突衰减”（如同时选“质数法则”与“全数字自由合并”，后者覆盖前者但得分-20%），强制玩家做策略取舍。

**局外永久成长（Meta进度）**
- **天赋树**：消耗局外货币解锁永久被动（如：开局自带1个随机技能、新数字生成概率偏向低值、图鉴掉落率+5%）。
- **主题解锁**：通过图鉴进度或成就解锁视觉包（魔法符文、细胞分裂、行星轨道），仅改变表现层，不影响数值平衡。
- **难度阶梯**：从“休闲（4x4）”→“进阶（5x5+障碍）”→“大师（动态规则+高生成率）”→“无尽（无限扩展）”，匹配不同玩家水平。

**收集与图鉴系统**
- 每次合成出里程碑数字（如64, 256, 1024, 2048）触发“进化动画”，记录至图鉴。
- 图鉴附带简短 lore 与合成路径提示，满足收集癖与策略参考需求。

### 数值框架
- **属性体系**：
  - `分数(Score)`：核心进度指标，影响难度曲线与局内资源产出。
  - `棋盘占用率(Grid%)`：动态难度核心参数，>70%时生成高数字概率提升，>90%触发“危机预警”。
  - `局内资源(Resource)`：用于释放技能，通过合并/完成挑战获取。
  - `规则权重(RuleWeight)`：控制多规则共存时的生效优先级与数值修正。

- **核心公式**：
  - **新数字生成概率**：`P(2) = 0.9 - (Score / 10000) * 0.4`，`P(4) = 0.1 + (Score / 10000) * 0.4`（保底2，随分数提升4的生成率，控制难度平滑上升）。
  - **得分计算**：`BaseScore = MergedValue * 10`，`ChainBonus = BaseScore * (1 + 0.15 * (ChainCount - 1))`，`TerrainBonus = BaseScore * Multiplier`。
  - **技能经济**：`SkillCost = BaseCost * (1 + 0.2 * RunDuration)`，随对局时间线性增长，防止后期技能滥用。
  - **局外货币产出**：`MetaCoin = floor(Score / 50) + AchievementBonus`，保证单局收益与投入时间正相关。

- **平衡原则**：
  1. **防滚雪球（Anti-Snowball）**：设置“动态生成补偿”，当玩家连续触发连锁或分数飙升时，短暂提高高数字生成率或减少技能资源产出，强制空间管理。
  2. **策略权重均等**：所有规则模组与技能经过“效用值(Utility)”校准，确保无绝对最优解。通过“规则冲突衰减”与“环境反制”（如特定障碍克制特定技能）维持多样性。
  3. **学习曲线阶梯**：新手期锁定规则选择，仅开放基础合并；第3局解锁1个模组；第5局开放技能；第10局开放完整构筑。避免信息过载。
  4. **容错与心流**：提供1次免费“悔棋”/“洗牌”保底，结合“危机预警”视觉提示，降低挫败感，维持“差一点就赢”的复玩动力。

### 玩法亮点
1. **动态规则引擎（Dynamic Rule Engine）**：打破传统2048固定逻辑，将“规则”本身变为可构筑的变量。玩家不再是被动适应系统，而是主动搭配规则组合（如“质数法则+连锁反应”），每局都是全新的解谜沙盒。
2. **生态棋盘与连锁反馈**：引入地形交互与连锁合并机制，将“滑动”升级为“路线规划”。一次精心策划的滑动可触发跨格连锁+地形倍率，产生强烈的视觉与数值爽感，形成记忆点。
3. **主题化数字进化图鉴**：将抽象数字转化为具象主题（如细胞分裂→器官→生命体；行星→恒星→星系）。每次突破里程碑伴随专属VFX与音效，结合图鉴收集系统，将“分数追求”转化为“内容收集”，大幅提升情感粘性。
4. **策略性空间管理**：在Roguelike随机性与固定棋盘限制之间取得平衡。玩家需权衡“保留空间等待高数字”与“提前合并释放技能”，结合规则模组的被动影响，形成“规划-执行-应变”的轻度策略深度，完美契合碎片化时间下的沉浸体验。
